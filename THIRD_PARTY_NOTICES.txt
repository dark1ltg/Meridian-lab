----------------------------------------------------------------------------
ffmpeg CLI (host — mood analysis; not bundled)
----------------------------------------------------------------------------
Meridian invokes a host `ffmpeg` binary on PATH for optional mood analysis.
Install it separately under whatever licence applies to your system package.

----------------------------------------------------------------------------
libx264 (host — not bundled)
----------------------------------------------------------------------------
libx264 is commonly GPL-2.0-only and must not be redistributed inside this
GPL-3.0-only AppImage. Bundled libavcodec may load the host libx264 at
runtime when present. Install your distribution’s x264 / libx264 package
(e.g. Arch/CachyOS: `pacman -S x264`). Meridian warns at startup if it is
missing while the FFmpeg media backend is in use.
