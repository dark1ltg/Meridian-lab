B. Other GPL / LGPL components redistributed in this AppImage
----------------------------------------------------------------------------

  Bundled native libraries (for example FFmpeg libav*, x265, Qt/PySide6 under
  LGPL-3 or GPL-3 as applicable) are recorded with build-host package names
  and versions in:

      usr/share/doc/meridian/third-party/BUILD_LIBRARIES.txt

  Corresponding Source for those components may be obtained, at no charge,
  from the same operating-system distribution / package archive that provided
  the recorded versions (for Arch Linux / CachyOS style hosts: the official
  package sources for the named packages at the recorded versions; for other
  hosts: the equivalent source packages or upstream release tarballs matching
  those versions). Licence texts for those components are included under:

      usr/share/doc/meridian/third-party/

  Qt for Python / Qt 6 libraries are offered under LGPL-3.0 (and optionally
  GPL-3.0) as separate components; full LGPL-3.0 and GPL-3.0 texts are in
  third-party/qt6/ and third-party/pyside6/.

  The mood-analysis `ffmpeg` CLI is a separate LGPL-2.1-or-later build of
  upstream FFmpeg. It is static, decode-only, and configured without
  `--enable-gpl`, without nonfree codecs, and without libx264 or libx265.
  The exact upstream tarball, version, and configure line are recorded in:

      usr/share/doc/meridian/third-party/ffmpeg-cli/FFMPEG_LGPL_BUILD.txt

  Corresponding Source for that binary is that upstream tarball, built with
  `packaging/build-ffmpeg-lgpl.sh` from the Meridian source that accompanies
  this AppImage. The LGPL-2.1 text shipped by upstream is in
  `third-party/ffmpeg-cli/COPYING.LGPLv2.1`.
